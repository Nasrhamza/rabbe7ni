# Architecture Decision Records

ADRs are immutable decision snapshots. A changed decision receives a new ADR with a `Supersedes`
reference.

Statuses:

- `Proposed`
- `Accepted`
- `Superseded`
- `Rejected`

Use [the template](0000-template.md) for new decisions.
